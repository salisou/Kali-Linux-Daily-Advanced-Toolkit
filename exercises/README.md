# Esercizi

Questa cartella raccoglie esercizi suddivisi per modulo.

## Come svolgerli

1. Leggere prima la lezione corrispondente.
2. Eseguire gli esercizi in un ambiente di laboratorio.
3. Annotare il comando utilizzato e il risultato ottenuto.
4. Spiegare con parole proprie cosa significa l'output.
5. Confrontare il risultato con le soluzioni solo dopo aver tentato.

## Formato consigliato per ogni esercizio

- **Obiettivo**
- **Scenario**
- **Comando da individuare**
- **Risultato atteso**
- **Domande di interpretazione**
- **Soluzione commentata**

Gli esercizi che modificano il sistema devono indicare chiaramente prerequisiti, rischi e procedura di ripristino.
